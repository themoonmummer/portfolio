## `ProjectWindow.tsx`

One train window. Props: `project: Project`.

- Outer frame: rounded rectangle with generously rounded corners (roughly `rounded-[2.5rem]`), a thick visible frame border (about 12–14px) in a warm dark metal tone, plus a thin inner lip so it reads as a real frame and not a card with a border.
- Fixed size, responsive: about 280px wide on mobile, 380px on sm, 460px on lg, with a 4:3 aspect ratio. The windows must not shrink — use `flex-shrink-0`.
- Inside the frame, a black inset "glass" area holding the media, clipped with `overflow-hidden` and matching inner radius.
- Media: if `project.videoSrc` exists, render `<video src autoPlay muted loop playsInline preload="metadata" poster={posterSrc}>` filling the area with `object-cover`. - Caption strip below the glass, still inside the frame: title and description, small type, muted.

### Marquee implementation — important

Do **not** use an index-based carousel or Framer Motion for this. Use a pure CSS transform loop:

1. Render the `projects` array **twice** inside a single flex track (`<div className="flex gap-8 w-max">`), with the duplicate marked `aria-hidden="true"`.
2. Animate the track with `@keyframes` from `translateX(0)` to `translateX(-50%)`, `linear`, `infinite`, duration around 40s (expose it as a CSS variable `--train-duration` so I can tune the speed).
3. Because the content is duplicated, `-50%` lands exactly where the loop began — that's what makes it seamless. Do not use a JS `setInterval` or scroll listener.
4. Add `will-change: transform` and `transform: translateZ(0)` on the track.
5. Do **not** pause on hover — it should never stop.
6. Under `@media (prefers-reduced-motion: reduce)`, stop the animation and let the strip scroll horizontally with `overflow-x: auto`.

Keep the keyframes in a scoped `<style>` block inside the component, and prefix the animation name (`train-scroll`) so it can't collide with anything global.

### Extras

- Fade masks on the left and right edges of the strip so windows fade out rather than getting cut off — use `mask-image: linear-gradient(to right, transparent, black 8%, black 92%, transparent)` with the `-webkit-` prefix too.
- Optional but nice: a very slow, subtle vertical bob (2–3px, ~6s) on the whole track to suggest train motion. Keep it barely perceptible.
- If a project has `href`, wrap the window in an anchor with a visible keyboard focus ring.
- TypeScript strict-safe, no `any`, no unused imports.
